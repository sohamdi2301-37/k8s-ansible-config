# k8s-ansible-config

Ansible playbooks and roles for Kubernetes node configuration, OS hardening, Node Exporter setup, Prometheus scrape targets, and Alertmanager configuration.

## Roles Included
- **node-setup:** Containerd runtime and OS hardening
- **node-exporter:** Node Exporter installation for metrics collection
- **prometheus-config:** Dynamic inventory and scrape target management
- **alertmanager-config:** Alertmanager rules and notification routing
